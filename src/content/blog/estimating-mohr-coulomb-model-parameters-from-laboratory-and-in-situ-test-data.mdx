## Executive Abstract

In computational geotechnics, constitutive modeling bridges geotechnical site characterization and numerical boundary value problems. Despite the emergence of advanced multi-surface plasticity formulations that capture stress-dependent stiffness, strain-hardening/softening, and small-strain non-linearity, the **linear elastic-perfectly plastic Mohr-Coulomb (MC) model** remains the primary benchmark across commercial finite element and finite difference codes (such as **PLAXIS 2D/3D**, **FLAC / FLAC3D**, **RS2 / RS3**, **MIDAS GTS NX**, and **GeoStudio SIGMA/W**).

\


The operational utility of the Mohr-Coulomb model hinges entirely on rigorous parameter calibration. Because the model idealizes complex soil mechanics into a constant elastic stiffness ($E, \nu$) bounded by a fixed hexagonal yield criterion ($c, \phi$) with a constant non-associated plastic potential ($\psi$), raw laboratory or field data cannot be imported indiscriminately without operational context.

\


This paper provides an end-to-end engineering guide to:

\


1. Mathematical formulations and mechanics of the MC model.


2. Derivation methodologies from laboratory triaxial ($CD/CU$) and direct shear ($DS$) testing.


3. Selection rules among **Undrained A, B, and C** modeling frameworks.


4. Empirical correlations with in-situ testing (**SPT, CPT, PMT, DMT**).


5. Numerical optimization and back-analysis using single-element digital twins.


6. Algorithmic and numerical modeling pitfalls encountered in finite element and difference solvers.



## 1. Constitutive Formulation and Yield Criteria

The classical Mohr-Coulomb criterion defines failure as a linear relationship between shear stress $\tau$ and effective normal stress $\sigma'\_n$ along an active failure plane:

\


$$\tau\_f = c' + \sigma'\_n \tan \phi'$$

In general three-dimensional stress space, defined by the principal effective stresses $\sigma'\_1 \ge \sigma'\_2 \ge \sigma'\_3$ (adopting geomechanics sign convention: compression positive), the yield function $F\_\{\text\{MC}} = 0$ is expressed as:

\


$$F\_\{\text\{MC}} = \frac\{1}\{2}(\sigma'\_1 - \sigma'\_3) + \frac\{1}\{2}(\sigma'\_1 + \sigma'\_3)\sin \phi' - c' \cos \phi' = 0$$

In invariant stress formulations using mean effective stress $p'$, deviator stress $q$, and Lode angle $\theta$:

\


$$p' = \frac\{1}\{3}(\sigma'\_1 + \sigma'\_2 + \sigma'\_3), \quad q = \sqrt\{\frac\{3}\{2}(\mathbf\{s} : \mathbf\{s})}, \quad \theta = \frac\{1}\{3} \arcsin \left( -\frac\{3\sqrt\{3}}\{2} \frac\{\det(\mathbf\{s})}\{q^3} \right)$$

where $\mathbf\{s} = \boldsymbol\{\sigma}' - p'\mathbf\{I}$ is the deviatoric stress tensor. The yield function takes the form:

\


$$F\_\{\text\{MC}} = p' \sin \phi' + q \left\[ \frac\{\cos \theta}\{\sqrt\{3}} - \frac\{\sin \theta \sin \phi'}\{3} \right] - c' \cos \phi' = 0$$

```
             OCTAHEDRAL PI-PLANE YIELD LOCUS
                         s'2
                          ^
                          |
                      /---\---\
                     /     |   \
                    /      |    \
                   /       |     \
                  |        +------|-----> s'1
                   \             /
                    \           /
                     \         /
                      \-------/
                     Mohr-Coulomb
                   (Hexagonal Cone)

```

### Plastic Potential Function and Non-Associated Flow

Soil shear deformation typically involves dilatancy. If an associated flow rule ($G \equiv F$) is enforced, the model predicts excessive plastic volume expansion:

\


$$\frac\{\dot\{\varepsilon}\_v^p}\{\dot\{\gamma}^p} = -\sin \phi'$$

Because real soils exhibit dilation angles ($\psi$) substantially smaller than their internal friction angles ($\phi'$), a **non-associated flow rule** ($G \neq F$) is mandatory:

\


$$G\_\{\text\{MC}} = \frac\{1}\{2}(\sigma'\_1 - \sigma'\_3) + \frac\{1}\{2}(\sigma'\_1 + \sigma'\_3)\sin \psi - \text\{constant} = 0$$

Plastic strain increments evolve orthogonal to $G$:

\


$$\dot\{\boldsymbol\{\varepsilon}}^p = \dot\{\lambda} \frac\{\partial G\_\{\text\{MC}}}\{\partial \boldsymbol\{\sigma}'}$$

```
                STRESS-STRAIN IDEALIZATION
   Deviator
   Stress (q)
       ^                 Real Soil Peak
       |                    /---\
       |                   /     \--- Real Soil Residual
       |                  /
  q_f  |-----------------+------------------ MC Yield Surface
       |                /|
       |               / |
       |              /  |
       |             /   |
       |            /    |
       |  Slope = E |    |
       +------------+----+--------------------> Axial Strain (e_a)
                    e_elastic

```

## 2. Model Parameters and Engineering Signatures

| **Parameter**                | **Symbol**        | **SI Units**       | **Mechanical Function in Numerical Formulations**                                                                         |
| ---------------------------- | ----------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| **Young's Modulus**          | $E$ (or $E'$)     | $\text\{kPa, MPa}$ | Governs pre-yield isotropic elastic stiffness; sets the elastic stiffness matrix $\mathbf\{D}^e$.                         |
| **Poisson's Ratio**          | $\nu$ (or $\nu'$) | $-$                | Controls elastic lateral straining ($\varepsilon\_3 / \varepsilon\_1$) and initial bulk-to-shear stiffness ratio ($K/G$). |
| **Effective Cohesion**       | $c'$              | $\text\{kPa}$      | Sets the failure envelope intercept; provides shear resistance under zero normal effective confinement.                   |
| **Friction Angle**           | $\phi'$           | degrees ($^\circ$) | Dictates the slope of the yield surface; controls normal stress-dependent frictional gain.                                |
| **Dilatancy Angle**          | $\psi$            | degrees ($^\circ$) | Governs plastic volumetric rate of expansion ($-\dot\{\varepsilon}\_v^p / \dot\{\varepsilon}\_a^p$) during yield.         |
| **Tensile Strength Cut-off** | $\sigma\_t$       | $\text\{kPa}$      | Explicit limit bounding the maximum allowable hydrostatic tensile stress ($\sigma\_t \le c' \cot \phi'$).                 |

### A. Triaxial Compression Testing ($CD$ and $CU$)

#### 1. Young's Modulus ($E\_\{50}$ vs. $E\_\{\text\{init}}$)

Because soil behavior exhibits continuous non-linearity from very small strain levels ($\varepsilon \< 10^\{-5}$), selecting an elastic modulus for the MC model requires matching the relevant operational stress-strain range.

\


```
                  SECANT MODULUS E50 EXTRACTION
     Deviator
     Stress (q)
         ^
   q_max |------------------------+----/------ Peak Stress
         |                       /    /
   q_50  |--------------+......./..../         0.5 * q_max
         |             /.      /    /
         |            / .     /    /  Slope = E50 = q_50 / e_50
         |           /  .    /    /
         +----------+---+---+----+------------> Axial Strain (e_a)
         0             e_50

```

1. Identify the maximum deviator stress $q\_\{\max} = (\sigma\_1 - \sigma\_3)\_f$ for a given effective confinement $\sigma'\_3$.


2. Compute the $50\\%$ deviatoric mobilization stress:

   \


   $$q\_\{50} = 0.5 \cdot q\_\{\max}$$
3. Project $q\_\{50}$ horizontally to intercept the primary loading curve; extract the corresponding axial strain $\varepsilon\_\{50}$.


4. Compute the secant modulus:

   \


   $$E\_\{50} = \frac\{q\_\{50}}\{\varepsilon\_\{50}} = \frac\{0.5 \cdot q\_\{\max}}\{\varepsilon\_\{50}}$$

*Practical Note:* Using initial tangent modulus ($E\_0$ or $E\_\{\text\{init}}$) severely overestimates soil stiffness over working load levels and underpredicts ground displacements. Conversely, using full failure secant modulus ($E\_\{\text\{fail}} = q\_\{\max}/\varepsilon\_\{\text\{fail}}$) yields excessive elastic deformations. Thus, $E\_\{50}$ represents the standard international industry consensus for working load conditions.

\


#### 2. Effective Shear Strength Parameters ($c', \phi'$)

Mohr Circles Method ($\tau - \sigma'$ Space)

For a multi-stage or multi-specimen triaxial series under effective confining pressures $\sigma'\_\{3,1}, \sigma'\_\{3,2}, \sigma'\_\{3,3}$:

\


1. Compute the major effective principal stress at failure:

   \


   $$\sigma'\_\{1,f} = \sigma\_\{3,f} + q\_\{\max} - u\_f$$
2. Construct Mohr circles with centers $C\_i$ and radii $R\_i$:

   \


   $$C\_i = \frac\{\sigma'\_\{1,f} + \sigma'\_\{3,f}}\{2}, \quad R\_i = \frac\{\sigma'\_\{1,f} - \sigma'\_\{3,f}}\{2}$$
3. Draw the straight linear tangent envelope across the circles:

   \


   $$\tau = c' + \sigma' \tan \phi'$$

```
                   MOHR CIRCLES AT FAILURE
    Shear
   Stress (t)
       ^                                    / Failure Envelope: t = c' + s'*tan(phi')
       |                                 /--
       |                              /--  \
       |                           /--      \     Angle = phi'
    c' |+                       /--          \   /
       | \                   /--  |           | /
       |  \               /--     |  Circle 2 |
       |   \           /--   Cir.1|           |
       +----+---------+-----------+-----------+--------> Normal Stress (s')
       0   s'3a      s'1a        s'3b        s'1b

```

Critical State Stress Invariant Method ($p' - q$ Space)

To eliminate graphical subjectivity, failure points are mapped to Cambridge stress space:

\


$$p'\_f = \frac\{\sigma'\_\{1,f} + 2\sigma'\_\{3,f}}\{3} \quad (\text\{triaxial compression convention}), \quad q\_f = \sigma'\_\{1,f} - \sigma'\_\{3,f}$$

Fit a linear regression line $q\_f = M p'\_f + d$. Convert parameters to the Mohr-Coulomb failure envelope:

\


$$\sin \phi' = \frac\{3M}\{6 + M} \iff M = \frac\{6 \sin \phi'}\{3 - \sin \phi'}$$

$$c' = d \cdot \frac\{3 - \sin \phi'}\{6 \cos \phi'}$$

#### 3. Dilatancy Angle ($\psi$)

Dilatancy captures plastic volumetric strain rate during shear:

\


```
                  VOLUMETRIC STRAIN RATE EXTRACTION
   Volumetric
   Strain (e_v)
    (+) Contraction
       ^        /---\ 
    0  +-------/-----\--------------------------------> Axial Strain (e_a)
       |      /       \    <-- Max Rate of Dilation: (-de_v / de_a)_max
    (-)|     /         \
    Dilation            \-----------------------------

```

From a drained triaxial ($CD$) test, extract the maximum rate of dilation $( -d\varepsilon\_v / d\varepsilon\_a )\_\{\max}$. Compute the dilatancy angle using the Hansen-Davis relation:

\


$$\sin \psi = \frac\{-\left(\frac\{d\varepsilon\_v}\{d\varepsilon\_a}\right)\_\{\max}}\{2 - \left(\frac\{d\varepsilon\_v}\{d\varepsilon\_a}\right)\_\{\max}}$$

*Bolton’s Empirical Formulation (for sands):*

When volumetric laboratory test data is unavailable:

\


$$\psi \approx \max \left( 0^\circ, \\, \frac\{\phi' - \phi'\_\{\text\{crit}}}\{0.8} \right) \approx \phi' - 30^\circ$$

### B. Direct Shear (DS) Testing

The Direct Shear test forces a planar horizontal failure surface:

\


* Normal effective stress: $\sigma'\_n = N / A$


* Shear stress: $\tau = T / A$



Plotting peak values of $\tau\_\{\max}$ versus $\sigma'\_n$ generates the envelope directly:

\


* **Friction Angle:** $\phi' = \arctan \left( \frac\{\Delta \tau}\{\Delta \sigma'\_n} \right)$


* **Cohesion:** $c' = \tau \text\{-axis intercept at } \sigma'\_n = 0$



```
                   DIRECT SHEAR FAILURE ENVELOPE
     Shear
    Stress (t)
        ^                                  / Failure Line: t = c' + s_n*tan(phi')
     t3 |................................./
        |                             .-/
     t2 |..........................--'
        |                      .--'  (s_n2, t2)
     t1 |...................--'      (s_n1, t1)
     c' |+..............---'         Angle = phi'
        +-----------+-----------+----------+----------> Normal Stress (s_n)
        0          s_n1        s_n2       s_n3

```

## 4. Modeling Undrained Soil Response: Selection Framework

When simulating low-permeability soils under rapid loading conditions relative to drainage rate, numerical engineers must select between **Effective Stress** and **Total Stress** frameworks.

\


```
                      UNDRAINED MODELING ARCHITECTURES
                      
                           Low Permeability Soil
                           
           +-------------------------+-------------------------+
           |                                                   |
           v                                                   v
   Effective Stress Approach                           Total Stress Approach
           |                                                   |
           v                                                   v
     [Undrained A]                                     [Undrained B / C]
- Drained c', phi', E', nu'                       - Undrained strength s_u
- Pore pressure generated via Bulk Modulus        - Friction phi_u = 0
  of water: K_w = 2*G*(1+nu_u) / (1-2*nu_u)       - Fast execution, zero pore pressure

```

### Framework Comparison Matrix

| **Property**              | **Undrained A (Effective Stress)**                                                                           | **Undrained B (Direct su​)**                            | **Undrained C (Total Stress)**                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- | -------------------------------------------------- |
| **Input Strength**        | Effective parameters ($c', \phi'$)                                                                           | Undrained shear strength ($s\_u, \phi\_u = 0$)          | Total strength ($c = s\_u, \phi = 0$)              |
| **Input Stiffness**       | Effective stiffness ($E', \nu' \approx 0.20-0.30$)                                                           | Effective stiffness ($E', \nu'$)                        | Undrained stiffness ($E\_u, \nu\_u \approx 0.495$) |
| **Excess Pore Pressure**  | Automatically generated via $K\_w$                                                                           | Explicitly calculated via total stress shift            | Not calculated ($\Delta u = 0$)                    |
| **Effective Stress Path** | Dependent on dilatancy ($\psi$)                                                                              | Uncoupled from pore fluid                               | Uncoupled / undefined                              |
| **Critical Warning**      | Setting $\psi > 0$ generates unrealistic negative pore pressures and overestimates undrained shear strength. | Requires specifying depth-dependent $s\_u(y)$ gradient. | Does not permit consolidation stages.              |

### Elastic Modulus Conversion

To convert between drained and undrained elastic moduli under invariant shear modulus $G$:

\


$$G = \frac\{E'}\{2(1 + \nu')} = \frac\{E\_u}\{2(1 + \nu\_u)}$$

$$E\_u = E' \cdot \left\[ \frac\{1 + \nu\_u}\{1 + \nu'} \right]$$

For incompressible undrained conditions ($\nu\_u \to 0.50$, practical numerical input $\nu\_u = 0.495$) and typical drained clay response ($\nu' \approx 0.20$):

\


$$E\_u = E' \cdot \left\[ \frac\{1 + 0.495}\{1 + 0.20} \right] \approx 1.25 \\, E'$$

## 5. In-Situ Field Test Parameter Correlations

When intact, undisturbed laboratory sampling is difficult, standardized field testing provides parameter estimates across international design practice.

\


```
                           IN-SITU FIELD SOUNDINGS
                           
        Standard Penetration (SPT)             Cone Penetrometer (CPT)
           |                                         |
           +--> (N1)_60 blow counts                  +--> Tip resistance q_c
           +--> Peck, Hanson & Thornburn             +--> Friction ratio R_f
           |    phi' = 27.1 + 0.3(N1)_60 - ...       |
           +--> Modulus: E = f(N60)                  +--> Robertson & Campanella
                                                     |    phi' = f(q_c / s'_v0)
                                                     +--> Modulus: E = alpha * q_c

```

### A. Standard Penetration Test (SPT)

Normalize raw blow count $N$ to energy efficiency ($60\\%$) and vertical overburden confinement ($\sigma'\_\{v0}$):

\


$$(N\_1)\_\{60} = N \cdot C\_E \cdot C\_B \cdot C\_S \cdot C\_R \cdot C\_N, \quad C\_N = \sqrt\{\frac\{p\_a}\{\sigma'\_\{v0}}} \le 1.7$$

1. **Friction Angle ($\phi'$):**

   \


   * *Peck, Hanson, and Thornburn (1974):*

     \


     $$\phi' \approx 27.1 + 0.30 \cdot (N\_1)\_\{60} - 0.00054 \cdot \left\[(N\_1)\_\{60}\right]^2$$
   * *Hatanaka and Uchida (1996):*

     \


     $$\phi' = \sqrt\{20 \cdot (N\_1)\_\{60}} + 20^\circ$$
2. **Young’s Modulus ($E$):**

   \


   * *Normally Consolidated Clean Sands:*

     \


     $$E \\, (\text\{MPa}) \approx 0.75 \cdot N\_\{60} \quad \text\{to} \quad 1.0 \cdot N\_\{60}$$
   * *Overconsolidated Sands / Sandy Gravels:*

     \


     $$E \\, (\text\{MPa}) \approx (1.2 \text\{ to } 2.0) \cdot N\_\{60}$$

### B. Cone Penetration Test (CPT)

1. **Friction Angle ($\phi'$ for clean sands):**

   \


   * *Robertson and Campanella (1983):*

     \


     $$\phi' = \arctan \left\[ 0.1 + 0.38 \cdot \log\left(\frac\{q\_c}\{\sigma'\_\{v0}}\right) \right]$$
   * *Kulhawy and Mayne (1990):*

     \


     $$\phi' = 17.5^\circ + 8.25 \cdot \log \left( \frac\{q\_\{c1}}\{\sqrt\{p\_a}} \right)$$
2. **Undrained Shear Strength ($s\_u$ for fine-grained soils):**

   \


   $$s\_u = \frac\{q\_t - \sigma\_\{v0}}\{N\_\{kt}}$$

   where $q\_t = q\_c + u\_2(1 - a)$ is corrected tip resistance, and $N\_\{kt} \in \[12, 18]$ (typically calibrated against field vane shear or triaxial CU tests).


3. **Young’s Modulus ($E\_\{50}$):**

   \


   * Clean Quartz Sands: $E = 2.5 \cdot q\_c$ to $3.5 \cdot q\_c$


   * Overconsolidated Sands: $E = 5.0 \cdot q\_c$


   * Cohesive Clays: $E\_u = (3 \text\{ to } 8) \cdot q\_t$



### C. Menard Pressuremeter (PMT) & Marchetti Dilatometer (DMT)

* **PMT:** Yields the pressuremeter shear/elastic modulus directly:

  \


  $$G = V \frac\{\Delta P}\{\Delta V}, \quad E\_\{\text\{PMT}} = 2(1 + \nu)G$$

  Because PMT creates lateral cavity expansion without specimen retrieval, the reload modulus $E\_r$ provides an operational baseline for deep excavation retaining walls and pile lateral deflections.


* **DMT:** Yields horizontal stress index $K\_D$, material index $I\_D$, and dilatometer modulus $E\_D$:

  \


  $$E\_D = 34.7 \cdot (p\_1 - p\_0)$$

  Constrained 1D modulus $M\_\{\text\{DMT}} = R\_M \cdot E\_D$, from which 3D elastic stiffness can be derived:

  \


  $$E = M\_\{\text\{DMT}} \cdot \frac\{(1 + \nu)(1 - 2\nu)}\{(1 - \nu)}$$

## 6. Soil-Structure Interface Mechanics ($R\_\{\text\{inter}}$)

In software packages such as PLAXIS, RS2, and MIDAS GTS NX, relative slip and gapping between soil and structural elements (retaining walls, anchors, piles, geotextiles) are resolved via zero-thickness joint interface elements.

\


```
                    INTERFACE REDUCTION LAW
                    
        +-----------------------------------------------+
        |    c_inter  = R_inter * c_soil                |
        |    tan(phi_inter) = R_inter * tan(phi_soil)   |
        |    psi_inter = 0                              |
        +-----------------------------------------------+

```

The reduction factor $R\_\{\text\{inter}} \le 1.0$ governs interface yield:

\


$$\tau\_\{\max} = c\_\{\text\{inter}} + \sigma'\_n \tan (\phi\_\{\text\{inter}})$$

$$c\_\{\text\{inter}} = R\_\{\text\{inter}} \cdot c\_\{\text\{soil}}, \quad \tan(\phi\_\{\text\{inter}}) = R\_\{\text\{inter}} \cdot \tan(\phi\_\{\text\{soil}})$$

$$\psi\_\{\text\{inter}} = 0^\circ \quad (\text\{slip surfaces do not maintain continuous dilation})$$

### Recommended Interface Reduction Factors

| **Structural Contact Interface**                        | **Characteristic Rinter​ Range** | **Standard Design Baseline** |
| ------------------------------------------------------- | -------------------------------- | ---------------------------- |
| **Rough Cast-in-Place Concrete vs. Sand / Clay**        | $0.80 - 1.00$                    | $0.90$                       |
| **Smooth Precast Concrete vs. Sand / Silt**             | $0.65 - 0.75$                    | $0.70$                       |
| **Steel Sheet Pile / Soldier Pile vs. Granular Soil**   | $0.50 - 0.65$                    | $0.55$                       |
| **Polymer Geogrid / Geotextile vs. Well-Graded Gravel** | $0.85 - 0.95$                    | $0.90$                       |
| **Bentonite Slurry / Mudcake Filter Cake vs. Clay**     | $0.30 - 0.40$                    | $0.35$                       |

*Pitfall:* Forgetting to apply $R\_\{\text\{inter}} \< 1.0$ artificially forces structural walls to adhere rigidly to the ground, underpredicting retaining wall deflections and overpredicting vertical interface shear transfer.

## 8. Step-by-Step Numerical Example: Parameter Derivation

### Problem Statement

A series of Consolidated Drained ($CD$) triaxial tests was conducted on undisturbed specimens of dense angular sand. The results from an isotropic baseline confinement of $\sigma'\_3 = 100.0\text\{ kPa}$ are:

\


* Peak deviatoric axial stress: $q\_\{\max} = 350.0\text\{ kPa}$ at $\varepsilon\_a = 4.2\\%$.


* Mobilized deviator stress at $50\\%$ yield: $q\_\{50} = 175.0\text\{ kPa}$ at $\varepsilon\_\{50} = 0.50\\% = 0.0050$.


* Volumetric-axial strain rate at maximum dilation: $\frac\{d\varepsilon\_v}\{d\varepsilon\_a} = -0.18$.


* Pre-failure elastic Poisson ratio from radial sensors: $\nu' = 0.26$.



### Step 1: Secant Elastic Stiffness ($E\_\{50}$)

$$E\_\{50} = \frac\{q\_\{50}}\{\varepsilon\_\{50}} = \frac\{175.0\text\{ kPa}}\{0.0050} = 35,000\text\{ kPa} = 35.0\text\{ MPa}$$

### Step 2: Major Effective Principal Stress at Failure ($\sigma'\_\{1,f}$)

$$\sigma'\_\{1,f} = \sigma'\_\{3,f} + q\_\{\max} = 100.0\text\{ kPa} + 350.0\text\{ kPa} = 450.0\text\{ kPa}$$

### Step 3: Effective Friction Angle ($\phi'$)

Assuming zero effective cohesion ($c' = 0$) for pure sands:

\


$$\sin \phi' = \frac\{\sigma'\_\{1,f} - \sigma'\_\{3,f}}\{\sigma'\_\{1,f} + \sigma'\_\{3,f}} = \frac\{450.0 - 100.0}\{450.0 + 100.0} = \frac\{350.0}\{550.0} = 0.63636$$

$$\phi' = \arcsin(0.63636) = 39.52^\circ \approx 39.5^\circ$$

*Numerical Adjustment for FE Stability:* To prevent matrix singularities at stress-free boundaries in the finite element mesh, prescribe an artificial cohesion $c' = 1.0\text\{ kPa}$. The adjusted friction angle is:

\


$$\sin \phi' = \frac\{\sigma'\_\{1,f} - \sigma'\_\{3,f}}\{(\sigma'\_\{1,f} + \sigma'\_\{3,f}) + 2 c' \cot \phi'}$$

For $c' = 1.0\text\{ kPa}$, $\phi'$ shifts slightly to $39.3^\circ$.

\


### Step 4: Dilatancy Angle ($\psi$)

1. **Hansen-Davis Kinematic Formula:**

   \


   $$\sin \psi = \frac\{-\left(\frac\{d\varepsilon\_v}\{d\varepsilon\_a}\right)}\{2 - \left(\frac\{d\varepsilon\_v}\{d\varepsilon\_a}\right)} = \frac\{-(-0.18)}\{2 - (-0.18)} = \frac\{0.18}\{2.18} = 0.08257$$

   $$\psi = \arcsin(0.08257) = 4.74^\circ \approx 4.7^\circ$$
2. **Bolton’s Empirical Relation (Verification):**

   \


   $$\psi \approx \phi' - 30^\circ = 39.52^\circ - 30^\circ = 9.52^\circ$$

   *Engineering Choice:* Using $\psi = 9.5^\circ$ assumes peak dilation rate across a broad shear zone, whereas $\psi = 4.7^\circ$ reflects the measured laboratory response, avoiding overprediction of passive resistance or wall heave. We adopt $\psi = 4.7^\circ$.



### Step 5: Summary Parameter Input Vector

```
Mohr-Coulomb Input Dataset:
- Model: Linear Elastic - Perfectly Plastic (Drained)
- E'     = 35,000 kPa (35.0 MPa)
- nu'    = 0.26
- c'     = 1.0 kPa (numerical stabilizer)
- phi'   = 39.5 deg
- psi    = 4.7 deg
- TenCut = Enabled (sigma_t = 0.0 kPa)

```

## 9. Numerical Calibration, Optimization, and Inverse Analysis

Laboratory parameters represent element-scale averages. Boundary frictions, end restraint platen constraints, and shear band localization cause laboratory test responses to deviate from pure element behavior.

\


```
                  DIGITAL TWIN CALIBRATION LOOP
                  
    +-------------------------+      +-------------------------+
    | Experimental Laboratory |      |   Single-Element FEA    |
    |      Test Data          |      |  (SoilTest / Script)    |
    +-------------------------+      +-------------------------+
                 |                                |
                 |          Residual Error        |
                 +----------->(e_k) <-------------+
                                |
                                v
                   +---------------------------+
                   | Levenberg-Marquardt / MCMC|
                   |   Optimization Engine     |
                   +---------------------------+
                                |
                                v
                   +---------------------------+
                   | Updated Parameter Vector  |
                   |   p = [E, nu, c', phi']   |
                   +---------------------------+

```

### Digital Twin Inverse Problem Formulation

Let $\mathbf\{y}\_\{\text\{exp}}(t)$ denote measured triaxial responses $\[q(t), \varepsilon\_v(t)]$ and $\mathbf\{y}\_\{\text\{num}}(\boldsymbol\{\theta}, t)$ denote the response predicted by a single-element numerical integration model with parameter vector $\boldsymbol\{\theta} = \[E\_\{50}, \nu, c', \phi', \psi]^T$.

\


The objective function $S(\boldsymbol\{\theta})$ minimizes weighted least-squares error:

\


$$S(\boldsymbol\{\theta}) = \sum\_\{k=1}^\{N} \left\[ \mathbf\{y}\_\{\text\{exp}}(t\_k) - \mathbf\{y}\_\{\text\{num}}(\boldsymbol\{\theta}, t\_k) \right]^T \mathbf\{W} \left\[ \mathbf\{y}\_\{\text\{exp}}(t\_k) - \mathbf\{y}\_\{\text\{num}}(\boldsymbol\{\theta}, t\_k) \right]$$

where $\mathbf\{W}$ is a diagonal weighting matrix that normalizes dimensional scales between deviator stress ($q$ in $\text\{kPa}$) and volumetric strain ($\varepsilon\_v$ dimensionless).

\


Parameters are updated iteratively using Gauss-Newton or Levenberg-Marquardt schemes:

\


$$\boldsymbol\{\theta}^\{(m+1)} = \boldsymbol\{\theta}^\{(m)} - \left\[ \mathbf\{J}^T \mathbf\{W} \mathbf\{J} + \mu \mathbf\{I} \right]^\{-1} \mathbf\{J}^T \mathbf\{W} \left( \mathbf\{y}\_\{\text\{exp}} - \mathbf\{y}\_\{\text\{num}}(\boldsymbol\{\theta}^\{(m)}) \right)$$

where $\mathbf\{J}\_\{ij} = \frac\{\partial y\_\{\text\{num}, i}}\{\partial \theta\_j}$ is the sensitivity Jacobian matrix.

\


## 10. Common Pitfalls and Numerical Stability Controls

```
                      NUMERICAL MODELING PITFALLS
                      
      Zero Cohesion               nu = 0.50             Infinite Dilation
     +--------------+          +--------------+          +--------------+
     |  sigma'3 = 0 |          |  K -> Infty  |          |  psi > 0     |
     |  Division by |          |  Plasticity  |          |  Unbounded   |
     |     Zero     |          | Solver Crash |          | Volume Gain  |
     +--------------+          +--------------+          +--------------+
            |                         |                         |
            v                         v                         v
     Apply c' = 1 kPa           Set nu = 0.25          Enable Void Ratio
                                                        Cut-Off Limit

```

### 1. Setting Effective Cohesion to Zero ($c' = 0$)

* **Mechanism:** At unconfined ground surfaces or above the phreatic line, normal effective confinement $\sigma'\_3 \to 0$. If $c' = 0$, shear capacity drops to zero ($\tau\_f \to 0$). In finite element models, stiffness integration matrices lose positive definiteness:

  \


  $$\det(\mathbf\{K}) \to 0$$

  This causes localized boundary node divergence, high out-of-balance forces, and solver termination.


* **Mitigation:** Apply a nominal artificial cohesion of $c' = 1.0 - 2.0\text\{ kPa}$ (or $20 - 40\text\{ psf}$). This stabilizes boundary element integration while having negligible impact on overall structural response.



### 2. Inputting $\nu = 0.50$ in Coupled Undrained Formulations

* **Mechanism:** Bulk modulus $K$ is defined by:

  \


  $$K = \frac\{E}\{3(1 - 2\nu)}$$

  As $\nu \to 0.50$, the denominator approaches zero ($1 - 2\nu \to 0$) and $K \to \infty$. In effective stress coupled formulations (e.g., PLAXIS Undrained A), this causes volumetric stiffness matrix singularities and immediate numerical divergence.


* **Mitigation:** Input the **drained** Poisson's ratio ($\nu' \approx 0.20 - 0.30$). The software introduces undrained incompressibility separately via the bulk modulus of water ($K\_w$).



### 3. Unbounded Plastic Dilation (Missing Dilatancy Cut-off)

* **Mechanism:** The Mohr-Coulomb model maintains a constant non-associated potential gradient $\frac\{\partial G}\{\partial \boldsymbol\{\sigma}'}$. Under continuous shear straining (e.g., large shear deformations along a slip surface), plastic volumetric expansion grows infinitely:

  \


  $$\Delta \varepsilon\_v^p \propto \Delta \gamma^p \sin \psi$$

  This produces artificially high passive soil resistance and excessive bottom heave in excavation analyses.


* **Mitigation:** Activate the **Dilatancy Cut-off** setting. This restricts plastic volumetric dilation once the soil reaches its maximum physical void ratio ($e\_\{\max}$):



$$\text\{If } e \ge e\_\{\max}, \quad \text\{enforce } \psi = 0^\circ$$

### 4. Overestimating Excavation Base Stability (Symmetric $E\_\{ur} = E$)

* **Mechanism:** The Mohr-Coulomb model enforces identical stiffness for virgin loading and unloading-reloading ($E\_\{\text\{reload}} = E\_\{\text\{virgin}}$). Real soils exhibit unloading stiffness $E\_\{ur}$ that is $3$ to $5$ times stiffer than primary loading stiffness $E\_\{50}$. Consequently, the MC model overpredicts bottom heave in deep excavation pits and miscalculates strut and anchor load shed distributions.


* **Mitigation:** For deep excavations and retaining systems, upgrade to advanced double-hardening formulations (such as the **Hardening Soil** or **HS-Small** models) that assign explicit stress-dependent unloading stiffness ($E\_\{ur}^\{\text\{ref}}$).



### 5. Tensile Zone Rupture Without Tension Cut-Off

* **Mechanism:** The linear MC envelope extends infinitely into the negative effective stress (tensile) quadrant. Soils cannot sustain significant tension, yet unconstrained elements near excavation faces or slope crests can develop tensile stresses up to:

  \


  $$\sigma\_\{t,\max} = c' \cot \phi'$$
* **Mitigation:** Enforce an explicit **Tension Cut-off** with $\sigma\_t \le 0.5 - 1.0\text\{ kPa}$ or set $\sigma\_t = 0\text\{ kPa}$.



## 11. Concluding Engineering Recommendations

1. **Stiffness Selection:** Always calibrate $E$ as a secant modulus $E\_\{50}$ derived at the in-situ operational stress level. Never use initial tangent moduli ($E\_0$) for working-state settlement analyses.


2. **Layer Sub-division:** When modeling deep deposits using Mohr-Coulomb, subdivide homogeneous strata into sub-layers with depth-increasing moduli, or specify an explicit depth-gradient parameter:

   \


   $$E(y) = E\_\{\text\{ref}} + E\_\{\text\{inc}} \cdot (y\_\{\text\{ref}} - y)$$
3. **Safety Analysis ($c\text\{-}\phi$ Reduction):** Limit equilibrium and finite element strength reduction methods ($c\text\{-}\phi\text\{ reduction}$) rely directly on the MC model. During reduction runs, set $\psi = 0^\circ$ to prevent unphysical kinematically forced strength increases from non-associated dilation.


4. **Model Progression:** Use Mohr-Coulomb as an initial benchmark to establish baseline equilibrium, verify global boundary conditions, and calculate primary Factors of Safety ($FoS$). For final deformation analysis involving sensitive adjacent infrastructure or deep excavations, transition to advanced constitutive models (**Hardening Soil**, **Modified Cam-Clay**, or **NorSand**).
